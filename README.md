# 🏎️ Nokia Racing Game

This project is a Java implementation of the classic Nokia Racing Game, developed as part of our **2nd Semester Object-Oriented Programming (OOP)** course. Instead of choosing a common management system, my project partner and I decided to recreate a game that many of us grew up playing while applying the OOP concepts we learned throughout the semester.

The game was built using **Java Swing** and focuses on creating a smooth gameplay experience while following proper object-oriented design.

## 📌 Project Information

**Course:** Object-Oriented Programming

**Semester:** 2nd Semester

**Institution:** COMSATS University Islamabad, Lahore Campus

## Features

* Three-lane racing track
* Smooth lane-changing animation
* Enemy cars in different colors
* Truck obstacles
* Speed control using arrow keys
* Difficulty increases as the player progresses
* Three lives system
* Explosion effect after collisions
* Temporary invincibility after each crash
* Live speed and distance display
* Pause and restart functionality
* Performance grading at the end of the game



## 🛠️ Technologies Used

- Java
- Java Swing (GUI)
- Java AWT
- Object-Oriented Programming (OOP)

## Controls

| Key           | Action                |
| ------------- | --------------------- |
| ⬅ Left Arrow  | Move Left             |
| ➡ Right Arrow | Move Right            |
| ⬆ Up Arrow    | Increase Speed        |
| ⬇ Down Arrow  | Decrease Speed        |
| P             | Pause / Resume        |
| Enter         | Start or Restart Game |



## How to Run

1. Make sure Java JDK 8 or above is installed.
2. Compile and run `Main.java`, or use the provided `run.bat` (Windows) or `run.sh` (Linux/macOS) file.
